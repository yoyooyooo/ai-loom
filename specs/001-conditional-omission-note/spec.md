# Feature Specification: 条件化省略说明（批注复制）

**Feature Branch**: `001-conditional-omission-note`  
**Created**: 2025-10-22  
**Status**: Draft  
**Input**: User description: "- 目前复制出来的批注prompt 无脑在顶部添加： - > 说明: 片段中若发生省略，将使用 <<<OMITTED ~N CHARS>>> 进行标记；请勿臆测缺失内容，定位以文件路径与行号为准。 - 我希望真正有省略的时候才补上这句话"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 含省略时自动添加说明 (Priority: P1)

当用户从界面复制“批注 prompt”，且被复制的片段中包含系统的省略占位符时，系统应在复制内容顶部自动添加一行说明（与现有中文提示文案完全一致），并与正文之间保留一个空行。

**Why this priority**: 直接影响阅读准确性与定位效率，属于主要用户价值路径。

**Independent Test**: 通过构造包含省略占位符的片段，点击“复制批注 prompt”即可独立验证是否附加了正确的单行说明且只出现一次。

**Acceptance Scenarios**:

1. **Given** 复制片段内包含系统省略占位符，**When** 点击“复制批注 prompt”，**Then** 复制内容第一行为既定说明文案，且仅出现一次，其后紧跟一个空行再进入正文。
2. **Given** 片段中存在多个省略位置，**When** 复制，**Then** 仅添加一行说明，不重复堆叠。

---

### User Story 2 - 无省略时不添加说明 (Priority: P1)

当用户复制的片段未发生省略时，复制结果不应包含任何额外的“省略说明”文字或多余空行。

**Why this priority**: 避免不必要噪声，提升可读性与专业感。

**Independent Test**: 通过构造无省略的片段进行复制，检查复制内容顶部不含说明行且无冗余空行。

**Acceptance Scenarios**:

1. **Given** 复制片段内不包含系统省略占位符，**When** 复制，**Then** 顶部不出现说明行；正文首行即为片段内容，无额外空行。

---

### User Story 3 - 文案与格式一致性 (Priority: P2)

当需要添加说明时，文案与当前系统使用的中文说明保持完全一致；说明行与正文之间固定保留一个空行；无论复制来源入口如何，表现一致。

**Why this priority**: 降低使用歧义，保障一致体验。

**Independent Test**: 从不同入口触发复制（如按钮/菜单/快捷键），在包含省略与不包含省略两类片段上验证文案与格式一致性。

**Acceptance Scenarios**:

1. **Given** 通过任意入口复制，**When** 出现省略，**Then** 说明文案一致且仅一行，说明与正文之间恰有一个空行。

---

### Edge Cases

- 片段正文中恰好包含与系统占位符相似的字符串（例如用户代码或注释内出现“<<<OMITTED ~123 CHARS>>>”样式）；避免误判。
- 片段存在多个省略位置时，不应重复插入多条说明。
- 复制来源入口不同（按钮/菜单/快捷键）导致行为不一致的风险。
- 复制结果前已有用户自定义头部文本时，新增说明的相对位置应保持在最顶端且不破坏原有顺序。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 当且仅当复制片段中包含系统的“省略占位符”时，复制结果顶部添加一行既定说明文案：
  - 说明: 片段中若发生省略，将使用 <<<OMITTED ~N CHARS>>> 进行标记；请勿臆测缺失内容，定位以文件路径与行号为准。
- **FR-002**: 无省略时，复制结果中不出现上述说明行，且不引入额外空行。
- **FR-003**: 若片段包含多个省略位置，说明行仅插入一次。
- **FR-004**: 说明行位置固定在复制内容最顶部；说明行与正文之间保留一个空行。
- **FR-005**: 判定依据为“复制内容中是否出现系统定义的省略占位符”，而非基于其他启发式信号。
- **FR-006**: 复制内容除上述规则外不被变更（不改动正文文本、缩进与换行）。
- **FR-007**: 所有触发“复制批注 prompt”的入口在同一版本中保持一致行为。
- **FR-008**: 该变更不影响用户的复制速度与操作流畅度（用户主观无延迟）。

*Assumptions & Dependencies*（说明性文字，非实现细节）

- 系统省略占位符格式稳定且唯一标识为“<<<OMITTED ~N CHARS>>>”（N 为字符数的数字占位）；以是否出现此占位符作为判定依据，以降低误判概率。
- 现有中文说明文案保持不变；暂不引入多语言版本。
- 各复制入口复用统一的复制逻辑；本版本覆盖所有“复制批注 prompt”的入口（按钮、右键菜单、快捷键），统一行为。

### Key Entities *(include if feature involves data)*

- **复制内容（Copied Prompt）**: 用户触发复制后得到的完整文本，由可选的“说明行 + 空行 + 正文”组成。
- **省略占位符（Omission Marker）**: 用于指示片段中有被省略的区段，其格式为“<<<OMITTED ~N CHARS>>>”。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在包含省略的测试样本中，复制结果顶部说明出现率为 100%；在不含省略的样本中，说明出现率为 0%。
- **SC-002**: 对于包含多个省略位置的样本，复制结果中说明行出现次数始终为 1（不重复）。
- **SC-003**: 用户触发复制到获取结果的主观体验“无额外等待”（实验中 95% 的复制在 0.2s 内完成）。
- **SC-004**: 发布后两周内，用户反馈中关于“无省略仍出现说明”的吐槽比例较基线下降 ≥ 80%。
- **SC-005**: 在随机抽样的无省略复制样本中，头部说明的误触发率 < 1%。
