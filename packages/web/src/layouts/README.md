# Layouts

该目录存放应用级布局组件与配置，不包含业务逻辑。多栏侧边栏改造引入的核心约束：

1. **首栏导航（Primary Sidebar）**：承载顶层模块列表（Chat、Explore 等），始终存在，可通过配置决定高亮与可见性。
2. **可选第二/第三栏**：模块可声明是否启用历史列表、上下文面板等附加信息；未启用时必须自动隐藏栏位与分隔线，不留下占位空白。
3. **主内容区**：各模块自带页面负责渲染主内容（如 ChatPanel、Explorer 编辑区域），布局层仅负责容器划分。
4. **响应式行为**：在 `md` 以下断点折叠为抽屉体验；使用 `useSidebar()` 提供的状态控制显示与动画。
5. **扩展约定**：新模块如需自定义栏位，必须通过 `SidebarModuleConfig` 声明，避免直接操作布局组件。

> 目录内文件需遵循 kebab-case 命名，所有导出均为具名导出，方便跨模块引用。
