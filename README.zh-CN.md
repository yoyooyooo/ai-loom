# ai-loom

本地优先的代码浏览与批注工作台。运行在任意项目中，快速查看文件、为代码添加批注，并从选中的上下文拼接高质量提示词（Prompt）——全程在本机完成。

- 后端：Rust（Axum）
- 前端：React + Vite
- 存储：SQLite（按工作区隔离）
- 分发：跨平台 CLI（`npx ai-loom`），仅绑定 127.0.0.1

## 核心特性
- 目录树快速浏览；遵循 .gitignore 与可选 .ailoomignore
- 沙箱访问：仅在指定根目录下读取/写入，越界保护
- 文件查看（可选编辑），内置 Monaco 与 Markdown 预览
- 批注创建/管理/验证：精确到行区间与选中文本，浮层交互
- Stitch 拼接：基于批注以「简洁/详细」模板与预算约束生成提示词
- 批注导入/导出；本地持久化配合乐观 UI
- 安全写入：摘要/冲突检测，避免意外覆盖

## 安装与运行
最简单的方式是使用 CLI（无需本地构建）。

- 先决条件：Node.js 18+

```bash
# 在你的项目根目录运行（将自动在浏览器打开）
npx ai-loom --root .
```

常用参数：
- `--port <number>`：指定端口（启动时会打印 AILOOM_PORT）
- `--db <path>` 或 `--db-path <path>`：自定义 SQLite 数据库存放路径
- `--no-open`：不自动打开浏览器

示例：
```bash
# 固定端口
npx ai-loom --root . --port 63000

# 将数据保存在项目内
npx ai-loom --root . --db ./.ailoom/ailoom.db
```

说明：
- 默认数据路径为 `~/ailoom/ailoom.db`；失败时会回退到项目内 `.ailoom/ailoom.db`
- 服务仅绑定 `127.0.0.1`，托管一个本地 Web 界面

## 快速上手
1) 在项目目录执行 `npx ai-loom --root .`
2) 应用会在浏览器打开；如未自动打开，可复制日志里的 URL（`http://127.0.0.1:<port>`）
3) 左侧树浏览文件；在查看器/编辑器中打开文件
4) 选择行或文本添加批注；在侧栏管理批注
5) 在 Stitch 面板选择批注并生成提示词
6) 需要共享或备份时，可将批注导出为 JSON

## 关键概念
- 工作区：按工作区隔离可见性。优先向上查找最近的 `.git` 作为工作区根；找不到则使用 `--root`
- 批注：附着在文件行区间与选中文本上的元数据（优先级、说明等），存储在 SQLite 中
- Stitch：基于预置模板与预算约束，从所选批注生成提示词

## 隐私与安全
- 本地优先：无遥测，不依赖外部服务即可使用
- 网络边界：仅绑定 `127.0.0.1`
- 文件边界：所有文件访问均在 `--root` 下进行；对二进制文件与大文件做防护与分页
- 忽略规则：遵循 `.gitignore` 与可选 `.ailoomignore`

## 支持平台
CLI 会根据平台选择已编译的后端二进制：
- macOS（Apple Silicon / x64）
- Linux x64（glibc 与 musl）与 Linux arm64（glibc 与 musl）
- Windows x64（MSVC）

## 常见问题
- 端口被占用：通过 `--port <number>` 更换端口
- 未自动打开浏览器：使用控制台打印的 URL `http://127.0.0.1:<port>`
- 批注数据位置：用 `--db`/`--db-path` 指定 SQLite 文件
- 大文件/二进制：大文件按页读取，二进制文件会检测并保护
